# Paradise Nursery

This is the final project for the "Paradise Nursery" shopping application. The front end interface allows users to browse a variety of houseplants, add them to a shopping cart, and manage the items before checkout.

## Features
- **Landing Page**: Provides a welcoming interface with a background image and company description.
- **Product Listing Page**: Displays a variety of houseplants organized into categories. Users can add plants to their shopping cart from this page.
- **Shopping Cart Page**: Allows users to view all selected items, adjust quantities, or remove items. It also displays the total number of items and the total cost.

## Technologies Used
- React.js
- Redux Toolkit (for state management)
- CSS (for styling)

## How to Run
1. Clone this repository.
2. Run `npm install` to install down dependencies.
3. Run `npm run dev` to start the application locally.
